# RobotCraft Studio

面向课堂演示的机器人创作仿真工作站。目标是让同一份文字或图案，通过笔、钻头或裱花嘴三类虚拟工具生成不同制作效果。

本项目仅做软件仿真，重点是路径规划、末端姿态、工艺动作和结果的可解释展示。

## 当前状态

2026-10-19：已完成 S1 笔绘基础仿真，包含八自由度机械臂、虚拟绘图笔、纸面、轨迹规划与实际笔迹。钻孔、裱花、SVG 导入和项目文件保存属于后续阶段。

技术路线采用 TypeScript、Vite、Three.js、Vitest。原生 DOM/CSS 组织交互，Worker 计算规划，按仿真时间播放；计算、播放与渲染分离。依赖锁定沿用旧项目，本次没有升级或增加依赖。

## 现在可以做什么

- 选择 ROBOT 字样、四笔汉字「中」、连续花形。
- 调整图案宽度、XY 摆放、目标速度与笔迹颜色。纸面固定为 0 mm，笔长固定为 24 mm，由工作站配置统一维护。
- 自动计算笔尖 TCP、竖直工具姿态、落笔/抬笔与关节轨迹；参数变更立即作废旧任务。
- 开始、暂停、继续、重播、0.5～4 倍速播放；重置同时清空笔迹和进度。
- 显示实际笔迹、可隐藏的目标辅助线、笔尖坐标轴与关节读数；支持俯视纸面和恢复视角。

笔迹使用实际关节轨迹的 FK 笔尖记录，空行程不留墨。纸面仅将接触容差内的实际 TCP 投影为笔迹；没有接触力或碰撞物理模型。

## 课堂演示步骤

1. 打开页面，等待“轨迹就绪”。
2. 选择汉字「中」，点击“开始绘制”，观察抬笔与四个笔画。
3. 暂停并展开“关节数据”，对照笔尖位置；调速后继续。
4. 点击“俯视纸面”，关闭“机械臂”和“目标辅助线”，检查实际作品。
5. 点击“重置”清空笔迹，修改图案或位置后比较。规划未通过时，调整参数再试。

## 验证

```powershell
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
```

当前 32 项测试覆盖旧算法回归、TCP/单位换算、三种预设规划、抬笔语义、参数校验、确定性播放和画板几何间隙。回归测试包含高画板穿模拒绝，以及连杆端点、段内插值与关节半径的检查。类型检查和完整生产构建已通过。

Windows 的构建入口会为子进程使用 `.cache/tmp`，避免当前机器共享临时目录中 esbuild 删除文件被拒绝；不修改系统环境或权限。构建输出独立的 Three.js、视角控制与规划 Worker 文件。

可通过 `npm.cmd run preview -- --host 127.0.0.1 --port 4174 --strictPort` 查看生产构建。

## 使用边界

- 偏差校验门槛为笔尖位置 0.5 mm、姿态 0.07 rad，数值采用本项目的虚拟尺度。
- 部分参数组合可能没有通过当前求解器校验；“未收敛”不代表已证明几何不可达，失败任务不会进入播放。
- 页面隐藏时暂停，返回后手动继续；图形上下文丢失时停止工作站并提示刷新。
- 当前只支持预设路径，尚不支持输入任意文字；钻孔、裱花尚未实现。
- 规划会以关节/连杆保守包络检查与画板的间隙，并检查段内插值姿态；自碰撞、其他物体碰撞和完整连续碰撞检测尚未实现。
